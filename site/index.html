Yama Museum Overview

Welcome to the Yama Museum documentation site. This repository visualizes and analyzes mountaineering location data (GPX) and activity logs from the YAMAP app.

Project Policies

  • Clone-Complete: A fresh Git clone contains primary data and retained processed artifacts needed for normal use.
  • No Git LFS: Git LFS is intentionally not used.
  • DVC-Light: DVC is used for pipeline metadata and reproducibility checks, not for removing primary data from Git by default.
  • Presentation Layer: This site is generated from canonical repository sources and does not expose raw/private/full data contents.
