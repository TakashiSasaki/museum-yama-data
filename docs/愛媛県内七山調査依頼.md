# **愛媛県内における特定7山岳の地理空間・歴史的総合調査報告書：緯度経度・標高・関連情報の統合解析**

愛媛県内の山岳地帯は、急峻な四国山地や石鎚山脈、法皇山脈を擁し、複雑な地形特性と豊かな歴史的背景を有している。しかし、同一または極めて類似した名称を持つ山岳（同名峰）が同一県内および近隣地域に複数存在することから、公共の地理空間データベースや各種登山プラットフォームにおいて、標高や緯度経度の「データの混同・誤認」が頻発している。  
本調査報告書では、対象となる7つの山岳について、正確な標高、地理的座標（緯度・経度）、三角点情報、登山ルート、歴史的背景を精査し、混同されやすい他地域の同名峰との比較を通じて、その全容を学術的かつ実証的に解明する。

## **2\. 各山岳の個別調査および詳細地理空間データ**

### **2.1. 新居浜市・四国中央市：権現山（別子銅山・赤石山系）**

新居浜市と四国中央市の境界に位置する「権現山」は、標高 1,594 \\text{ m}（または 1,593 \\text{ m}）の急峻な高標高峰である 。別子銅山を包含する広義の赤石山系（東赤石山、西赤石山、物住頭など）に属し、肉淵林道から二ッ岳、エビラ山、黒岳、そして権現山へと至る縦走路は、四国地方の登山道の中でも「最難関」の一つとして知られている 。

#### **2.1.1. 地理空間データと同名峰との相違**

一般の登山サイト等では、愛媛県内の別の「権現山」と混同される例が極めて多い。特に、宇和島市に位置する「権現山」は標高 952.7 \\text{ m} であり、二万五千分の一地形図「宇和島」に登録されている 。この宇和島市の権現山の座標は、北緯 33^\\circ 10' 58''、東経 132^\\circ 35' 43'' であるが 、これが誤って別子・赤石山系の権現山に適用されているケースがあるため、注意が必要である。また、瓶ヶ森手前のUFOライン近隣にある「子持権現山」（高知県いの町／愛媛県西条市境、標高 1,677 \\text{ m}）も近接する同名峰として挙げられる 。

#### **2.1.2. 関連情報と登山環境**

別子・赤石山系の権現山山頂付近は険しい岩場が連続するが、5月中旬から下旬にかけてはアケボノツツジやシャクナゲの見事な群生が見られ、過酷なルートに挑む登山者の目を楽しませる 。

### **2.2. 大洲市：高森山**

大洲市に存在する「高森山」は、大洲市河辺町に位置する標高 820 \\text{ m} の山岳である 。本峰は、中世の山城である「高森城（高森城址）」が築かれた歴史の山であり 、歴史地理的観点から極めて高い価値を有している。

#### **2.2.1. 地理空間データと同名峰との相違**

愛媛県内には、四国百名山（81座目）に選定されている「高森山」（西予市と宇和島市の境界、標高 634 \\text{ m} または \[span\_24\](start\_span)\[span\_24\](end\_span)635 \\text{ m}）が存在する 。こちらの西予・宇和島境の高森山は「四国の道」が整備され、山頂に芝生広場や東屋がある観光地化された山である 。また、喜多郡内子町には標高 309 \\text{ m} の低山としての「高森山」（三等三角点「村前」：北緯 33^\\circ 33' 01.4272''、東経 132^\\circ 40' 10.2054''）が存在する 。これらに対し、大洲市河辺町の高森山は標高 820 \\text{ m} と最も高く、地域的な独立性を保っている 。

#### **2.2.2. 関連情報と登山環境**

大洲市河辺町の高森山へは、大中山集落からのアプローチのほか、林道高森線を利用して頂上直下まで車輛でアクセスすることが可能である 。山頂付近はスギの植林帯に覆われているが、周囲の見晴らしは良く、歴史的には坂本龍馬が土佐を脱藩する際に通ったとされる「龍馬脱藩の道」が横断・交差する要衝でもある 。

### **2.3. 四国中央市・西条市：大森山**

「大森山」は、愛媛県東部の四国中央市と西条市の市域、あるいは近隣自治体との境界に位置する 。

#### **2.3.1. 地理空間データと同名峰との相違**

国土地理院のデータおよび各種データベース上、このエリアには以下の「大森山」が存在する：

* **大森山（四国中央市と高知県長岡郡本山町境）：** 標高 1,433 \\text{ m} 。四国中央市山間部の登録座標として、北緯 33^\\circ 52' 46.7''（33.879645^\\circ）、東経 133^\\circ 32' 37.2''（133.543653^\\circ）が一般に示される 。 \* **大森山（西条市）：** 標高 1,399 \\text{ m} 。

これら東部の峻険な大森山に対し、西側の南予地域である大洲市と喜多郡内子町の境界には、標高 729 \\text{ m} の同名峰「大森山」が存在する 。大洲・内子境の大森山には、三等三角点「三久保」（北緯 33^\\circ 31' 0\[span\_36\](start\_span)\[span\_36\](end\_span)1.6113''、東経 132^\\circ 43' 33.1731''、標高 729.11 \\text{ m}）が配されている 。四国中央市および西条市の大森山は、これら南予の低山帯とは異なり、四国山地の主稜線や法皇山脈の延長上に位置する高標高の境界峰である。

### **2.4. 久万高原町：笠松山**

上浮穴郡久万高原町東明神に位置する「笠松山」は、標高約 850 \\text{ m}（等高線判断 850 \\text{ m} 以上、GPS実測値で約 855 \\text{ m}）の山岳である 。

#### **2.4.1. 地理空間データと同名峰との相違**

本峰の測量上の注意点として、山頂に「三角点が存在しない」という特徴が挙げられる 。また、一部の地図や資料において標高が「868 \\t\[span\_46\](start\_span)\[span\_46\](end\_span)ext{ m}」と記載されている場合があるが、これは笠松山の北隣にある別のピークの標高点（868 \\text{ m}）であり、笠松山自体の山頂標高ではない 。 近隣には「餓鬼ヶ森」（四等三角点「餓鬼ケ森」：北緯 33^\\circ 41' 27.3629''、東経 132^\\circ 54' 19.8088''、標高 954.44 \\text\[span\_48\](start\_span)\[span\_48\](end\_span){ m}） や、「船山」（三等三角点「船山」：北緯 33^\\circ 41' 53.4183''、東経 132^\\circ 53' 11.0521''、標高 910.02 \\text{ m}） が聳えており、久万高原町の東明神エリアにおいて山塊を共有している。 なお、今治市と西条市の境界には、別名「伊予の剣」と呼ばれる有名な「世田山」と縦走路で結ばれた「笠松山」（標高 357 \\te\[span\_50\](start\_span)\[span\_50\](end\_span)xt{ m}、二等三角点「笠松山」：北緯 33^\\circ 58' 49.1783''、東経 133^\\circ 02' 11.7651''、標高 327.73 \\text{ m}）が存在するが、久万高原町の笠松山とは位置も歴史的コンテキストも全く異なる 。

#### **2.4.2. 歴史的背景（笠松城址）**

久万高原町の笠松山山頂には、「笠松城址」の石碑が建立されている 。笠松城は天正2年（1574年）頃、鶴原和泉守三郎兵衛が居城したと伝えられる 。河野氏の計らいにより大洲から久万大除城に迎えられた大野氏の支城（ネットワーク城砦）として機能し、南方の土佐国から勢力を伸ばす長宗我部元親軍の伊予侵攻を阻止するための最前線防衛拠点であった 。  
\#\#\# 2.5. 新居浜市：東山  
新居浜市別子山地域に位置する「東山」は、標高 1,392 \\text{ m} の山岳である 。四国山地西部の石鎚山地・赤石山系に属し、四国屈指の人気峰である「西赤石山」（標高 1,625.8 \\text{ m}）へと至る主稜線上に位置している 。

#### **2.5.1. 地理空間データと測量情報**

山頂の標識の直下には三角点が設置されている 。正確な地理座標は公開された測量点に準ずるが、本峰は別子銅山の悲劇的な歴史を今に伝える峠である「銅山越」（標高 1,294 \\text{ m} / 北緯 33^\\circ 51' 44''、東経 133^\\circ 19' 32'' ）の至近（約 0.5 \\text{ km} 東側）に位置しており、座標的にも極めて近い特性を有する。

#### **2.5.2. 登山ルートと銅山遺構**

一般的なアプローチは、南側の別子山地域にある「日浦登山口」を起点とする 。ここからかつての別子銅山の繁栄と生活 of 跡を残す石垣や煉瓦壁、ダイヤモンド水、歓喜坑などの遺構を巡りながら登り、約1時間強で「銅山越」に達する 。銅山越から東方向へ稜線を進み、天満山（標高約 1,360 \\text{ m}）を経由して複数の偽ピーク（アップダウン）を越えることで、東山の山頂に至る 。東山からはさらに「西赤石山」への快適な笹尾根の縦走路が続いており、銅山峰ヒュッテに宿泊して東赤石山までを縦走するハイカーの主要な経由地となっている 。

### **2.6. 宇和島市：大黒山**

宇和島市に位置する「大黒山（オオグロヤマ／ダイコクヤマ）」は、標高 1,105.8 \\text{ m} の山岳である 。

#### **2.6.1. 地理空間データと同名峰との相違**

本峰は、愛媛県宇和島市（旧津島町）、高知県四万十市（旧西土佐村）、および宿毛市の3市境が交わる地点に位置し、高知県宿毛市の「最高峰」でもある 。山頂には三等三角点「御内（みうち）」（標高 1,106.2 \\text{ m}）が配されている 。 一方、東予の西条市黒谷（三芳大字旦之上）には、標高 322 \\text{ m} の別名「炭谷山」と呼ばれる「大黒山」が存在し、その山頂付近（西条市三芳）に四等三角点「大黒」（標高 392.54 \\text{ m}、北緯 33^\\circ 56' 53.1561''、東経 133^\\circ 01' 00.7274''）が設置されている 。両者は同じ愛媛県内でありながら、地理的スケールも標高も大きく異なる。

#### **2.6.2. 登山史と環境的特色**

宇和島市の大黒山は、大正末期から「宇和島五山」（篠山、大黒山、譲ヶ葉、鬼ヶ城、高月山）の一座として広く親しまれ、活発に登られてきた登山史を有している 。山容は非常になだらかで、山頂周辺は落葉広葉樹林に覆われ、下草の少ない快適な環境が維持されている 。北西に位置する「大峠」からは、コンクリートを一切使用せずに岩盤を素掘りした歴史的な「大峠隧道」を通過するルートがあり、往時の土木技術を伝える景観が残されている 。

### **2.7. 四国中央市：大野山**

四国中央市における「大野山」は、山岳データベース上の検索等において「情報の混同」が最も極端に発生している、極めて特殊なケースである。

#### **2.7.1. データベースの混同実態**

多くのデジタル地図プラットフォームや検索エンジンにおいて、「四国中央市 大野山」として検索を行った場合、神奈川県足柄上郡山北町に実在する「大野山」（標高 723 \\text{ m}、山頂付近に1968年開設の牧場が存在する山 ）のGPSログデータや写真 が紐付けられて表示される現象が確認されている。 神奈川県の大野山山頂の緯度経度は北緯 35^\[span\_89\](start\_span)\[span\_89\](end\_span)\\circ 23' 12.5''（約 35.3868^\\circ）、東経 139^\\circ 02' 56.2''（約 139.0490^\\circ）付近であり 、四国地方とは全く異なる。また、愛媛県内における別の著名な大野山としては、西予市野村町付近（大野ヶ原近隣）に位置する「宇和の大野山」（標高 802.0 \\text{ m}）が知られている 。

#### **2.7.2. 四国中央市における局地呼称としての検証**

四国中央市において「大野山」と呼ばれる峰は、法皇山脈や四国山地の複雑な地脈の中に埋もれた、国土地理院の主要測量点に登録されていないローカルな微地名、あるいは山地の一角を指す固有呼称である可能性が高い。四国中央市内の最高標高点自体は「東赤石山」（標高 1,706 \\text{ m}／実標高 1,710 \\text{ m}）などの主要峰が占めており 、大野山という名称に関する信頼性の高い緯度経度・三角点情報を確定するためには、データベース上の誤統合データを排除した上で、法皇山脈北麓・南麓の地域誌や地籍図を用いた、さらなる現地実地調査が必要とされる。

## **3\. 結論**

本調査により、愛媛県内の同名峰が抱える地理空間データ上の混乱が浮き彫りとなった。別子山系の険しい「権現山（1,594 \\text{ m}）」と南予の「権現山（952.7 \\text{ m}）」、大洲市の城址である「高森山（820 \\text{ m}）」と四国百名山の「高森山（635 \\text{ m}）」、久万高原町の城塞都市の歴史を刻む「笠松山（約 850 \\text{ m}）」と今治の「笠松山（357 \\text{ m}）」は、それぞれ全く異なる地形的、歴史的アイデンティティを有している。デジタル社会における地理データの信頼性を維持するためには、測量点（三角点）の公式名称および詳細な座標を個別に対照し、自動化された機械学習やクローリングに伴う混同バグを注意深く排除する、専門的な査読プロセスが不可欠である。
