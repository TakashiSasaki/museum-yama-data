# Merge Address to GPX

This skill reads geocoded address data from JSON files (typically generated by the `reverse-geocode-points` skill) and merges that information into an existing GPX file containing waypoints.

For each waypoint in the GPX file, it attempts to find a matching coordinate in the JSON files. If a match is found, the script updates the waypoint by:
1. Appending the formatted Japanese address to the existing `<desc>` tag.
2. Injecting structured address data into custom `<address:*>` tags within the `<extensions>` block.

## Requirements

The skill requires Node.js and the `xml2js` library.
Before running, install dependencies:

```bash
cd .agents/skills/merge-address-to-gpx
npm install
```

## Usage

```bash
node .agents/skills/merge-address-to-gpx/merge_address.js --gpx <input.gpx> --json-dir <reverse_geocoding_dir> --out <output.gpx>
```

### Parameters

*   `--gpx`: The path to the source GPX file (e.g., `gpx/all_unique_summits.gpx`).
*   `--json-dir`: The directory containing the output JSON files from the reverse geocoding step (e.g., `reverse_geocoding/`). The script will load and combine all `.json` files in this directory.
*   `--out`: The path where the new GPX file should be saved (e.g., `gpx/all_unique_summits_with_address.gpx`). The original GPX file will not be overwritten.

### Example Output

The updated GPX will include an `xmlns:address="http://example.com/address"` namespace at the root level and update matched waypoints as follows:

```xml
<wpt lat="33.7675949" lon="133.1152818">
  <ele>1979.1701508543217</ele>
  <name>天狗岳</name>
  <desc>Peak detected at 1979m (prominence: 472m)
[Address] 愛媛県西条市三の鎖</desc>
  <sym>Summit</sym>
  <extensions>
    <address:prefecture>愛媛県</address:prefecture>
    <address:city>西条市</address:city>
    <address:local>三の鎖</address:local>
  </extensions>
</wpt>
```
