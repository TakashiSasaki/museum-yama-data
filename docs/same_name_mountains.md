## 共通する重要発見

1. **3名すべてが「同名異山」**：mountains.json の `municipalities` リストが複数自治体にまたがる場合、それは1つの山ではなく **物理的に別の山々が同じ名前で1エントリ化されているサイン** と読むべき
2. **黒森山 A の自治体補完**：松山市のみ書かれているが、実は松山市・久万高原町境界。これは佐々木さんが指摘されていた「`municipalities` リスト不完全」のもう一つの例
3. **典拠の強さ階層**：
   - 強：笹ヶ峰 A（一等三角点）、黒森山 A（三等三角点「黒森」）
   - 中：笹ヶ峰 B（四国百名山）、黒森山 B（YAMAP登録、地理院地図注記あり）
   - 弱：愛宕山 A・B（地理院三角点として確認できず、通称名扱い）

## 推奨アクション

- **黒森山**：mountains.json 1エントリを 2レコードに分解。自治体リストは A（松山市・久万高原町）、B（西条市）に整理
- **笹ヶ峰**：mountains.json 1エントリを 2レコードに分解。自治体リストは A（西条市、高知県境界）、B（四国中央市、高知県境界）に整理
- **愛宕山**：mountains.json 1エントリを 2レコードに分解。さらに「典拠は通称名（神社由来）」と注記。**追加調査の余地あり**（県内に他にも存在する可能性が高い）
